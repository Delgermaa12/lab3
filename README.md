## Сценарио 1: Performance — /cart/add

| Хэсэг | Агуулга |
|---|---|
| Тойм | /cart/add endpoint хэвийн ачаалалд хэр хурдан хариулдгийг шалгах |
| Системийн төлөв | Сервер хэвийн ажиллагаанд, унаагүй |
| Орчны төлөв | 20 VU тогтмол ачаалал, ойролцоогоор 20 хүсэлт/с |

| Хэмжүүр | Хариу хугацааны p95 < 200мс байх ёстой |

## Сценарио 2: Reliability — /pay

| Хэсэг | Агуулга |
|---|---|
| Тойм | /pay endpoint-ийн эвдрэлийн (алдааны) давтамжийг шалгах |
| Системийн төлөв | Сервер хэвийн ажиллагаанд, гэхдээ санамсаргүй алдаа гаргах боломжтой |
| Орчны төлөв | 20 VU ачаалал, 1 минутын турш |
| Гадаад өдөөлт | Хэрэглэгч төлбөр хийх хүсэлт илгээв (POST /pay) |

| Хэмжүүр | Алдааны хувь (error rate) < 8% байх ёстой |

| Хэсэг | Агуулга |
|---|---|
